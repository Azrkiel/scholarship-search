# applications/

Working folder for in-progress applications. The agent creates one subfolder per
award, e.g. `applications/jane-doe-nursing-award/`, holding draft essays, a materials
checklist, and any pre-filled forms.

**Everything in here except this README is gitignored** — it contains your essays and
personal details, and this repo is public. The drafts stay on your machine until you
review and submit them yourself.
